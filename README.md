# ریحون | سیستم اشتراک و حسابداری آشپزخانه

اپلیکیشن اندروید کامل برای **آشپزخانه ریحون** شامل بخش مشتری و پنل ادمین با سیستم حسابداری.

## ویژگی‌های اصلی

### بخش مشتری
- ورود با کد اشتراک
- مشاهده و ویرایش آدرس تحویل
- مشاهده منوی غذا و قیمت‌ها
- نمایش وضعیت بدهی

### پنل ادمین / حسابداری
- **داشبورد فروش**: گزارش روزانه، هفتگی و ماهانه (فروش کل، دریافتی، بدهی)
- **مدیریت منو**: افزودن / حذف غذا با قیمت و دسته‌بندی
- **مدیریت مشتریان**: افزودن مشتری، آدرس، کد اشتراک
- **ثبت سفارش**: انتخاب مشتری + غذاها + پرداخت جزئی یا کامل
- **بدهی و تسویه**: ثبت بدهی هنگام سفارش ناقص و تسویه بعدی

## جریان کار حسابداری
1. ادمین مشتری و منو را تعریف می‌کند.
2. هنگام ثبت سفارش می‌تواند مبلغ پرداختی را کمتر از جمع وارد کند → مابه‌التفاوت به بدهی مشتری اضافه می‌شود.
3. بعداً از بخش مشتریان می‌تواند پرداخت بدهی را ثبت کند.
4. گزارش‌های فروش به‌صورت لحظه‌ای به‌روز می‌شوند.

## تکنولوژی
- Kotlin + Jetpack Compose + Material 3
- Navigation Compose
- UI واکنش‌گرا برای تمام سایزها
- RTL و فارسی کامل
- Min SDK 24 | Target 34

## اجرا
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync
3. Run

یا از تب **Actions** روی گیت‌هاب APK را دانلود کنید.

## نکته
داده‌ها در حافظه نگهداری می‌شوند (برای دمو و استفاده محلی). برای نسخه تولیدی می‌توان به Room یا Firebase متصل کرد.
